# Crédits photographiques

Les neuf photographies des fiches espèces viennent de Wikimedia Commons. Toutes sont sous
licence Creative Commons, qui impose de citer l'auteur : cette page est cette citation, et elle
est reprise dans les mentions légales du site (écran 6).

Chaque image a été redimensionnée à 800 px de large et recompressée — 884 Ko pour les neuf,
contre 6 Mo pour les originaux. C'est une mesure d'éco-conception, pas un détail technique.
